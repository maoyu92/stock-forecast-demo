## 1. 背景与目标

V1.0 已有 2 个选股方法。本次将选股器升级为**通达信式多策略选股器**：

- **G1**：仿照通达信"公式系统"，实现一个**通达信语法子集的公式引擎**，选股策略全部用公式表达（通达信 `.tn6` 完全加密无公开解密方案，故走"自建公式库"路线，而非解析通达信文件）。
- **G2**：内置 **116 个公式选股策略**（12 大类），含市面经典开源策略（均线/MACD/KDJ/RSI/BOLL/量价/K线形态/海龟等）与**缠论简化实现**，以及从用户材料整理的 **均线金三角托、金蜘蛛、揉搓线（低位看涨/高位看跌）**。
- **G3**：解决"通达信能下载大量历史数据，我们怎么拿"的问题——建立**本地历史K线仓库**（SQLite），全市场日K一次性下载、每日增量更新，选股完全跑在本地数据上（与通达信"下载盘后数据→本地选股"同思路）。

## 2. 数据调研结论（2026-09-12 实测）

| 方案 | 结论 |
|---|---|
| 读取通达信本地数据（`vipdoc/**/lday/*.day`） | **可行但本机未装通达信客户端**。已实现解析器（32字节/条记录，无加密，见 `services/tdxfile.py`），配置 `TDX_VIPDOC_PATH` 即可启用；注意通达信本地数据**不复权** |
| pytdx/mootdx（通达信行情服务器协议） | 可行，但本机网络对部分行情主机不稳，未引入（避免额外依赖） |
| **baostock（已采用为主源）** | ✅ 实测可用：前复权、全历史；单只 2 年日K 约 1.5~2s |
| akshare/新浪（备源） | ✅ 可用（约 1.1s/只），已作为项目内备源保留 |
| 东财 push2 | ❌ 本机被重置连接（V1 快照链路已有 push2delay 回退） |

**结论**：数据与通达信同源（公开行情），且我们额外提供**前复权**（通达信本地文件没有）。
全市场 5219 只 × 2 年首次全量约 20~40 分钟（4 进程并发），之后每日增量约 5 分钟。

## 3. 架构

```
前端 智能选股页
  ├─ 数据管理面板（覆盖股票数/数据截至日/同步进度轮询，增量/全量按钮）  ←→  /api/data/status  /api/data/sync
  └─ 策略分组选择（10 大类 112 公式 + 2 快照）→ 参数表单（含 select 类型）→ /api/screener/run
后端
  ├─ services/tdxfile.py          通达信 .day 文件解析（可选源）
  ├─ services/histstore.py        本地K线仓库：多进程同步/增量/除权漂移整窗重下/进度状态
  ├─ services/screener/
  │    ├─ base.py                 策略注册表（新增 kind/category/formula 字段 + select 参数）
  │    ├─ moneytree/smartmoney    V1 实时快照策略（保留）
  │    └─ formula/
  │         ├─ engine.py          通达信公式引擎（词法→AST→pandas 向量化求值）
  │         ├─ catalog.py         112 个策略公式目录（注册时全量编译验证）
  │         └─ runner.py          全市场扫描：读本地K线→求值→信号→强度百分位打分
数据（SQLite）
  ├─ kline_daily(code,date,OHLCV,amount)   全市场日K（前复权）
  └─ kline_meta(code,name,first/last_date,rows)
```

### 3.1 公式引擎（engine.py）

支持：`OPEN/HIGH/LOW/CLOSE/VOL/AMOUNT` 引用；`:=` 中间变量与 `:` 输出线（最后一条输出线为信号）；
运算与逻辑；注释 `{}` `//`；约 35 个函数：`MA EMA SMA WMA HHV LLV HHVBARS LLVBARS REF CROSS COUNT
EVERY EXIST BARSLAST BARSCOUNT SUM ABS MAX MIN IF POW SQRT LN LOG EXP SIGN MOD STD VAR AVEDEV
VALUEWHEN CONST FILTER BACKSET BETWEEN UPNDAY DOWNNDAY SAR`。

- 语义对齐通达信：`CROSS`=上穿、`BARSLAST`=距上次成立天数、`SMA(X,N,M)` 递归平滑等。
- **刻意不实现 `ZIG/PEAK` 等未来函数**（会用未来数据，选股结果会"回看修正"）。
- 求值全向量化：320 根日K × 1 公式 ≈ 2.7ms/股；全市场 5000 只单公式 8 线程约 10~30s。
- 公式可带**参数**（如金叉周期 `N1/N2`）与**强度输出线**（`STRENGTH:`，用于命中结果百分位打分）。

### 3.2 本地历史仓库（histstore.py）

- 同步模式：`update` 增量（last_date 前推 12 天抓取并替换该区间）/ `full` 整窗重下；
- **除权漂移自愈**：增量时若重叠区收盘价对不上（期间除权导致前复权基准变化），自动把该股票
  加入第二轮整窗重下；
- **进程池健壮性**：worker 初始化登录一次（避免 131 批次反复登录被限流）、单批次 5 分钟看门狗、
  池崩坏自动重建并重排未完成批次（最多 3 轮）；
- 被限流/失败的股票不写 meta，下次增量自动按全窗口补抓。

其中用户材料整理的 4 个：

- **均线金三角托**：5上穿10 → 5上穿20 → 10上穿20 依次金叉形成封闭三角，附加"20日线拐头向上"
  的趋势前提（材料：最好出现在多头趋势回调到位后再启动的拐点）。
- **均线金蜘蛛**：三线粘合（间距≤2%）后发散为多头排列并放量确认。
- **低位揉搓线（看涨）**：先上影T形线、后下影T形线 + 缩量 + 处于60日区间低位 45% 以下
  （材料：低位为锤头线+倒锤头线组合，看涨，常为主升段前兆）。
- **高位揉搓线（看跌，风险提示类）**：同一组合出现在60日区间高位 70% 以上
  （材料：为上吊线+射击之星组合，看跌）。

### 4.1 通用扫描参数（每个公式策略都带）

| 参数 | 默认 | 说明 |
|---|---|---|
| 信号有效期 within_n | 1 | 信号出现在最近 N 个交易日内即命中 |
| 选股范围 board | 全部 | 全部A股 / 沪深主板 / 创业板 / 科创板 |
| 剔除 ST exclude_st | 开 | 按名称过滤 |
| 信号日成交额下限 | 0（不过滤） | 排除流动性过差个股 |

命中结果的"强度分"= 强度公式（各策略定义，如金叉发散度、量比）在全部命中中的**百分位**（0~100）；
未定义强度式的策略恒为 100。快照策略（摇钱树/主力动向）仍为因子加权得分。

## 5.1 多策略组合选股（交集/并集/排除）

通达信式"条件组合"的量化实现：

- **并集（任一命中）**：扩大候选池，适合"多思路撒网"；得分取命中策略中最高强度分。
- **交集（全部命中）**：多条件共振提纯，如"均线金叉 ∩ MACD金叉 ∩ 放量突破 − 顶分型"；
  得分取各命中策略强度分的平均。
- **排除集（差集）**：命中排除策略（如顶分型、断头铡刀等风险提示类）的股票直接剔除。
- 实现：`run_multi_strategy` 单次遍历全市场，每只股票**读一次K线同时评估全部公式**
  （K线 I/O 与重复求值是大头，多策略耗时与单策略相当，实测 2~3 个策略约 80~110 秒）。
- 限制：仅公式策略可参与组合（实时快照策略数据口径不同）；交集至少 2 个策略；
  组合模式下公共参数（信号有效期/板块/ST/成交额）统一生效，各策略专属参数用默认值。

## 6. 使用方式（通达信式工作流）

1. **下载数据**：选股页顶部"历史数据仓库"卡片 → 增量更新（每日收盘后一次）；
2. **选股**：选策略（可搜索）→ 调参数 → 开始选股（全市场本地扫描，10~60 秒）；
3. 结果按强度分排序，可展开查看命中详情（关键指标值），CSV 导出、保存历史、一键"去预测"。

## 7. 边界与说明

- 涨停判定为 `涨幅≥9.7% 且收盘=最高` 的近似口径（主板精确；20cm 股自然覆盖，非涨停大涨且收最高价者可能误报）。
- 缠论策略为**简化量化**（未做包含关系处理与笔/段完整递推），命名已标注"简化"。
- 背离类公式为"简化判定"（创新低/新高 + 指标未同步），非严格缠论/股道标准。
- 北交所暂未纳入本地仓库；ETF/指数不参与选股。
- 免责声明：选股结果由历史数据量化规则生成，仅供研究参考，不构成投资建议。
