# 个人炒股工作台 · 产品设想与路线图（Roadmap）

> 目标：做一个**自己用的** A 股看盘/选股/预测一体化小工具。不求大而全，按"一个炒股的人每天/每周的固定动作"来组织功能。
> 本文档 = 用户习惯 → 功能地图 → 实施排期。

## 1. 一个炒股的人有哪些习惯（= 功能来源）

| # | 习惯/动作 | 频率 | 对应功能（已有✅ / 规划○） |
|---|---|---|---|
| 1 | 盘前看指数、看自选股集合竞价 | 每日早 | ○ 行情中心指数条 + 自选列表（含竞价快照） |
| 2 | 复盘看自选股走势（分时/日K + 指标） | 每日 | ✅ 行情中心：分时/日K/周K/月K + MACD/KDJ/RSI/BOLL/VOL 副图 |
| 3 | 分组管理标的（主线/备选/周期/次新…） | 随时 | ✅ 自选分组（增删改、组内快照涨跌） |
| 4 | 用条件筛选股票（形态/指标/量价） | 不定期 | ✅ 116 策略公式选股 + 交集/并集/排除组合 |
| 5 | 把选出的票加入自选跟踪 | 每次选股后 | ○ 选股结果"一键加入自选分组"（接口已就绪，差前端按钮） |
| 6 | 交易后记账（买卖点/仓位/盈亏） | 每笔 | ○ 交易日志（journal）：记录买卖理由、截图、复盘标签 |
| 7 | 验证策略有效性（历史胜率） | 每周/月 | ✅ 全市场全策略回测（1/3/5/10日胜率/均收益/盈亏比/综合分，`scripts/backtest.py`）；✅ 每日荐股 = 头部策略组合 + 质量门控 + 空仓纪律（`scripts/daily_pick.py` + 每交易日 17:30 定时任务） |
| 8 | 看消息面/公告/龙虎榜 | 每日 | ○ 东财/新浪公告与龙虎榜聚合（数据源受限，尽力而为） |
| 9 | 大盘情绪（涨跌家数/涨停数/炸板率） | 每日 | ○ 市场情绪面板（腾讯/新浪接口可拼出涨跌家数） |
| 10 | 长期资产曲线与复盘 | 每月 | ○ 收益曲线：以交易日志为基础画净值曲线 |

**核心闭环**：选股 → 看图（行情中心）→ 加自选 → （可选）预测/回测 → 交易日志 → 复盘。

## 2. 已完成（截至 2026-09-12）

- 智能选股：116 策略（114 公式 + 2 快照）、多策略组合（交集/并集/排除）、历史K线仓库（5196 只/255 万行，日增量同步）
- 行情中心（本轮新增）：自选分组 CRUD + 腾讯/新浪实时快照轮询 + 五大指数条 + 分时（均价线）/日K/周K/月K（ECharts 蜡烛 + MA + MACD/KDJ/RSI/BOLL/VOL 副图切换）
- TimesFM 多因子预测、预测历史
- 组合策略组回测（本轮新增）：5 个完整买卖策略组，支持 ATR 止损、均线破位、时间退出、手续费/印花税/滑点、T+1、涨跌停近似约束、单票仓位与组合最大持仓，输出净值曲线、回撤、胜率、盈亏比和逐笔交易明细；CLI / API / 前端页面均已接入。

## 3. 排期建议（按依赖与价值排序）

### P1（下一轮，小改动）
1. **选股结果一键加自选**：结果表加"加自选"按钮（选分组）——闭环第 5 步。
2. **自选列表右键/按钮直接跑某个选股策略**（对单票反查信号）。
3. **K线图叠加选股信号标记**：选中策略的历史信号在K线上打点（数据已具备，`run_formula` 的信号 Series 全量返回即可）。

### P2（中期）
4. **指标公式图表化**：把 PriGS.dat 提取出的自建指标（买卖线/主力监测器/绝佳买卖等，见 `docs/PriGS提取_明文公式.txt`）移植为可渲染公式——引擎需补 `STICKLINE/COLORx/DRAWTEXT/LINETHICK/DRAWNULL/FORCAST/ZTPRICE` 等绘图函数子集，输出"画图指令序列"给前端 ECharts 渲染。**这会让你在通达信里惯用的指标原样出现在自己的工具里。**
5. **简单回测**：策略 → 信号列表 → 前向收益统计（1/3/5/10 日均值/胜率/盈亏比）。纯本地计算，无交易成本建模（简化）。✅ 已实现更进一步的组合策略组回测（持仓状态机 + 止损/止盈/时间退出 + 成本 + 组合风控）。
6. **市场情绪面板**：涨跌家数/涨停数/炸板率（腾讯全市场快照聚合，一次请求可算）。

### P3（按需）
7. **登录**：单用户方案（自己用不搞多用户注册）：`.env` 配 `APP_PASSWORD`，登录后发签名 token（HMAC），FastAPI 中间件校验 `/api/*`；前端登录页 + localStorage 存 token。**建议真的要暴露到公网/手机访问时再做**，纯局域网自用不必。
8. **交易日志与收益曲线**：journal 表（日期/代码/方向/价格/数量/理由/情绪标签）+ 净值曲线页。
9. **盘中提醒**（可选，Windows 本机跑）：自选股触发某公式信号 → 系统通知。
10. **移动端适配**：行情中心响应式已可用，进一步做窄屏布局。

## 4. 技术备忘

- 行情源：腾讯 `qt.gtimg.cn` 快照（主）/ 新浪 `hq.sinajs.cn`（备）；分时与指数K线走新浪 `CN_MarketDataService`（5 分钟K聚合，日K scale=240）。东财 push2 本机被墙不依赖。
- 个股历史K线：本地 `kline_daily`（前复权），超过本地的部分与指数/ETF 实时走新浪。
- 自选/分组/（未来）交易日志都落 SQLite，与选股历史同库。
- 免责：所有数据与信号仅供个人研究，不构成投资建议。
