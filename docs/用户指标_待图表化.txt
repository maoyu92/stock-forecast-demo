# 用户提供的通达信指标公式（待图表公式子系统移植）

## 《机构散户资金监控 精简优化版》（副图指标）

移植阻塞点（日K数据 + 当前引擎均不支持）：
- DYNAINFO(n)：盘中实时动态数据（现价/内盘等），日K口径无意义
- COST(5)/COST(95)：筹码分布成本线，需要换手率衰减的筹码模型
- CAPITAL：流通股本（本仓库K线无此字段）
- DRAWICON / DRAWTEXT_FIX / CON2STR / STICKLINE / POINTDOT / NODRAW：绘图与文本函数，
  属于 P2「指标公式图表化」范围（引擎需输出画图指令序列）

核心可计算逻辑（届时可直接复用）：
- A2~A5：按"单日成交额阈值"划分机构/散户 × 阳线/阴线 的累计成交额
- 强势: 100*A2/A6>50；拉升: 机构净占比>18 且 机构买占比-散户卖占比>18
- JJ1:=SUM(V*C,0)/SUM(V,0) 累计均价；地:=EMA(JJ1,50)/0.97
- 顶底多空: DMP/DMM(DMI式) + COST 近似顶底线
